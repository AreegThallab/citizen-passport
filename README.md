# 🇸🇦 جواز المواطن | Citizen Passport

**جواز المواطن** هو مشروع ويب تفاعلي مبني باستخدام **Django**، تم تطويره كتجربة رقمية بمناسبة **اليوم الوطني السعودي**.

تقوم فكرة المشروع على إنشاء **جواز تذكاري رقمي** يأخذ المستخدم في رحلة تفاعلية عبر عدد من مناطق المملكة العربية السعودية. يمر المستخدم على خمس محطات، وفي كل محطة يتعرف على أحد المعالم أو العناصر الثقافية المرتبطة بالمنطقة، ويجيب على سؤال بسيط للحصول على **ختم رقمي** داخل جوازه.

بعد إكمال الرحلة وجمع الأختام، يستطيع المستخدم إنشاء **بطاقة تذكارية بصيغة PNG** تحمل اسمه وأختامه، ثم تحميلها أو مشاركتها عبر الجهاز.

> المشروع تذكاري وغير رسمي، ولا يمثل أي جهة حكومية ولا يستخدم هوية أو شعارات حكومية رسمية.

## 💡 فكرة المشروع

بدلًا من إنشاء صفحة تقليدية للاحتفال باليوم الوطني، تم تصميم المشروع كتجربة تفاعلية تجعل المستخدم يشارك في رحلة صغيرة داخل المملكة.

تبدأ التجربة بإصدار جواز رقمي للمستخدم باستخدام:

- الاسم.
- رمز شخصي يختاره المستخدم.

بعد ذلك يبدأ المستخدم رحلته بين المحطات، ويتعرف في كل محطة على معلومة مرتبطة بتاريخ المملكة أو ثقافتها أو معالمها.

عند الإجابة الصحيحة، يحصل المستخدم على ختم خاص بالمحطة، ويتم تسجيل تقدمه حتى يكمل جميع المحطات.

الهدف هو الجمع بين:

**التقنية + التفاعل + الثقافة السعودية + تجربة المستخدم.**

## 🚀 قابلية تطوير الفكرة

تم بناء النسخة الحالية كنموذج أولي قابل للتوسع مستقبلًا.

يمكن تطوير **جواز المواطن** ليشمل:

- إضافة جميع مناطق المملكة ومحافظاتها.
- إضافة مسارات مختلفة للمعالم التاريخية والتراث والثقافة والأكلات الشعبية والوجهات السياحية.
- إنشاء مستويات وتحديات مختلفة.
- إضافة نظام نقاط وإنجازات.
- إضافة Leaderboard للمستخدمين.
- استخدام QR Codes في الفعاليات والمعارض للحصول على الأختام.
- ربط التجربة بمواقع فعلية بحيث يحصل المستخدم على الختم عند زيارة الموقع.
- إنشاء جوازات خاصة بالمناسبات والفعاليات المختلفة.
- إضافة لوحة تحكم لإدارة المحطات والأسئلة والمحتوى دون تعديل الكود.
- دعم لغات متعددة.
- تطوير نظام مشاركة اجتماعية للبطاقات والإنجازات.
- تحويل المشروع مستقبلًا إلى Progressive Web App أو تطبيق للهواتف.

الفكرة الأساسية للمشروع لا تعتمد فقط على اليوم الوطني؛ يمكن إعادة استخدام نفس النظام لإنشاء **رحلات رقمية تفاعلية للفعاليات، السياحة، المتاحف، الجامعات والمعارض.**

## 📍 المحطات

| المحطة | المحتوى |
|---|---|
| الرياض | قصر المصمك |
| مكة المكرمة | الرواشين في جدة التاريخية |
| المدينة المنورة | جبل الفيل في العلا |
| عسير | فن القط العسيري |
| المنطقة الشرقية | مركز إثراء |

كل محطة تحتوي على:

- صورة توضيحية محلية.
- سؤال اختيار من متعدد.
- تلميح عند الحاجة.
- معلومة قصيرة مرتبطة بالمحطة.
- ختم رقمي يضاف إلى الجواز بعد الإجابة الصحيحة.

- واجهة عربية بالكامل تدعم `RTL`.
- تصميم Responsive يعمل على الجوال والحاسوب.
- تصميم مستوحى من مفهوم الجواز والأختام.
- إنشاء جواز باسم المستخدم ورمز شخصي.
- خمس محطات تفاعلية.
- حفظ الأختام والتقدم.
- منع تكرار الختم لنفس المحطة.
- إمكانية حذف الجواز والبدء من جديد.
- إنشاء بطاقة تذكارية بصيغة PNG.
- مشاركة البطاقة عبر إمكانات الجهاز عند توفر Web Share API.
- لا يتطلب تسجيل دخول أو بيانات شخصية حساسة.

## 🔐 الخصوصية

تم تصميم المشروع بحيث لا يحتاج إلى إنشاء حساب مستخدم تقليدي.

لا يتم طلب بيانات شخصية حساسة، ويعتمد الجواز فقط على:

- الاسم المدخل.
- الرمز المختار.
- Session الخاصة بالمتصفح.

ويتم ربط الجواز والأختام بجلسة المستخدم.

## 💾 حفظ التقدم

يتم تخزين بيانات الجواز والأختام في قاعدة البيانات وربط الجواز الحالي بالمستخدم عن طريق **Django Session**.

إذا تم حذف Cookies أو Session الخاصة بالمتصفح، فقد لا يتمكن المستخدم من الوصول إلى نفس الجواز مرة أخرى، بينما يبقى السجل محفوظًا في قاعدة البيانات حتى يتم حذفه.

## 💻 التشغيل محليًا

### Windows

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver
```

ثم افتح:

```text
http://127.0.0.1:8000/
```

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
```

## ⚙️ Django Admin

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

ثم:

```text
http://127.0.0.1:8000/admin/
```

تعرض لوحة الإدارة الجوازات والأختام، بينما توجد بيانات المحطات والأسئلة حاليًا داخل:

```text
journey/data.py
```

ومن التطويرات المستقبلية الممكنة نقل إدارة هذا المحتوى بالكامل إلى قاعدة البيانات ولوحة Django Admin.
