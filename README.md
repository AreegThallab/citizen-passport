# 🇸🇦 جواز المواطن | Citizen Passport

**جواز المواطن** هو مشروع ويب تفاعلي مبني باستخدام **Django**، تم تطويره كتجربة رقمية بمناسبة **اليوم الوطني السعودي**.

تقوم فكرة المشروع على إنشاء **جواز تذكاري رقمي** يأخذ المستخدم في رحلة تفاعلية عبر عدد من مناطق المملكة العربية السعودية. يمر المستخدم على خمس محطات، وفي كل محطة يتعرف على أحد المعالم أو العناصر الثقافية المرتبطة بالمنطقة، ويجيب على سؤال بسيط للحصول على **ختم رقمي** داخل جوازه.

بعد إكمال الرحلة وجمع الأختام، يستطيع المستخدم إنشاء **بطاقة تذكارية بصيغة PNG** تحمل اسمه وأختامه، ثم تحميلها أو مشاركتها عبر الجهاز.

> المشروع تذكاري وغير رسمي، ولا يمثل أي جهة حكومية ولا يستخدم هوية أو شعارات حكومية رسمية.

---

## 💡 فكرة المشروع

بدلًا من إنشاء صفحة تقليدية للاحتفال باليوم الوطني، تم تصميم المشروع كتجربة رقمية تفاعلية تجعل المستخدم جزءًا من الرحلة.

تبدأ التجربة بإصدار جواز رقمي باسم المستخدم ورمز يختاره، ثم ينتقل المستخدم بين عدد من المحطات المستوحاة من مناطق المملكة.

في كل محطة يتعرف على معلومة مرتبطة بتاريخ المملكة أو ثقافتها أو معالمها، ثم يجيب على سؤال بسيط للحصول على ختم خاص بالمحطة.

بعد جمع جميع الأختام، يكتمل الجواز ويمكن للمستخدم إنشاء بطاقة تذكارية وتحميلها أو مشاركتها.

الهدف من المشروع هو الجمع بين:

**التقنية + التفاعل + الثقافة السعودية + تجربة المستخدم.**

---

## 🚀 قابلية تطوير الفكرة

تم بناء النسخة الحالية كنموذج أولي قابل للتوسع مستقبلًا.

يمكن تطوير **جواز المواطن** ليشمل:

- إضافة جميع مناطق المملكة ومحافظاتها.
- إنشاء مسارات مختلفة للمعالم التاريخية والتراث والثقافة والأكلات الشعبية والوجهات السياحية.
- إضافة مستويات وتحديات مختلفة.
- إضافة نظام نقاط وإنجازات.
- إضافة Leaderboard للمستخدمين.
- استخدام QR Codes في الفعاليات والمعارض للحصول على الأختام.
- ربط التجربة بمواقع فعلية بحيث يحصل المستخدم على الختم عند زيارة الموقع.
- إنشاء جوازات رقمية لفعاليات ومناسبات مختلفة.
- إضافة لوحة تحكم لإدارة المحطات والأسئلة والمحتوى.
- دعم لغات متعددة.
- تطوير نظام مشاركة اجتماعية للبطاقات والإنجازات.
- تحويل المشروع مستقبلًا إلى Progressive Web App أو تطبيق للهواتف.

الفكرة الأساسية للمشروع لا تعتمد فقط على اليوم الوطني، بل يمكن إعادة استخدام نفس النظام لإنشاء **رحلات رقمية تفاعلية للفعاليات، السياحة، المتاحف، الجامعات والمعارض.**

## 📍 المحطات

تتضمن النسخة الحالية خمس محطات من مناطق مختلفة في المملكة:

| المحطة | المحتوى |
|---|---|
| الرياض | قصر المصمك |
| مكة المكرمة | الرواشين في جدة التاريخية |
| المدينة المنورة | جبل الفيل في العلا |
| عسير | فن القط العسيري |
| المنطقة الشرقية | مركز إثراء |

كل محطة تحتوي على:

- صورة توضيحية.
- سؤال اختيار من متعدد.
- تلميح عند الحاجة.
- معلومة قصيرة مرتبطة بالمحطة.
- ختم رقمي يضاف إلى الجواز بعد الإجابة الصحيحة.

## 💾 حفظ التقدم

يتم تخزين بيانات الجواز والأختام في قاعدة البيانات.

ويتم ربط الجواز الحالي بالمستخدم عن طريق **Django Session**.

بالتالي يستطيع المستخدم التنقل بين صفحات المشروع مع استمرار تقدمه في نفس الجلسة.

إذا تم حذف Cookies أو Session الخاصة بالمتصفح، فقد لا يتمكن المستخدم من الوصول إلى نفس الجواز مرة أخرى، بينما يبقى السجل محفوظًا في قاعدة البيانات حتى يتم حذفه.

## 💻 التشغيل محليًا

### Windows

أنشئ البيئة الافتراضية:

```powershell
py -m venv .venv
```

ثبت المتطلبات:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

شغّل migrations:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
```

شغّل السيرفر:

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

ثم افتح:

```text
http://127.0.0.1:8000/
```

---

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
```

ثم افتح:

```text
http://127.0.0.1:8000/
```

## 🌐 Deployment

المشروع مجهز للنشر باستخدام **Render**.

بيئة الإنتاج تعتمد على:

- Gunicorn لتشغيل Django.
- WhiteNoise لخدمة الملفات الثابتة.
- PostgreSQL لقاعدة البيانات.
- Environment Variables لحفظ الإعدادات الحساسة.

أمر التشغيل:

```bash
gunicorn config.wsgi:application
```

ويتم استخدام:

```text
build.sh
```

لتثبيت المتطلبات، جمع الملفات الثابتة وتشغيل migrations أثناء عملية النشر.
