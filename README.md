# جواز المواطن

مشروع ويب تفاعلي مبني بـ Django لفعالية اليوم الوطني السعودي. الفكرة عبارة عن جواز تذكاري رقمي يمر فيه المستخدم على خمس محطات من مناطق المملكة، يجاوب على سؤال بسيط في كل محطة، ثم يحصل على ختم داخل الجواز. بعد جمع الأختام يمكن تحميل بطاقة تذكارية بصيغة PNG أو مشاركتها.

المشروع مصمم كتجربة خفيفة ومباشرة: لا يوجد تسجيل دخول، ولا يتم طلب بيانات شخصية حساسة. الجواز يعتمد على الاسم والرمز المختار، ويحفظ التقدم في جلسة المتصفح.

## المحتوى

التجربة تحتوي على خمس محطات:

| المحطة | الفكرة |
|---|---|
| الرياض | التعرف على قصر المصمك |
| مكة المكرمة | التعرف على الرواشين في جدة التاريخية |
| المدينة المنورة | التعرف على جبل الفيل في العلا |
| عسير | التعرف على فن القط العسيري |
| الشرقية | التعرف على مركز إثراء |

كل محطة تحتوي على:

- صورة محلية توضيحية.
- سؤال اختيار من متعدد.
- تلميح عند الحاجة.
- معلومة قصيرة بعد الحصول على الختم.
- ختم يظهر في صفحة الجواز.

## المميزات

- واجهة عربية RTL متجاوبة مع الجوال والحاسوب.
- خط ثمانية مضمّن محليًا داخل المشروع.
- إصدار جواز باسم المستخدم ورمز بسيط.
- خمس محطات تفاعلية مع أختام محفوظة في قاعدة البيانات.
- منع تكرار الختم لنفس المحطة.
- صفحة جواز تعرض التقدم والأختام.
- بطاقة تذكارية PNG ترسم محليًا عبر JavaScript وتستخدم نفس الخط.
- مشاركة البطاقة عبر إمكانات الجهاز عند توفرها.
- إمكانية حذف الجواز والبدء من جديد.
- بدون خدمات خارجية مطلوبة أثناء الاستخدام المحلي.

> الجواز تذكاري وغير رسمي، ولا يستخدم شعارات حكومية أو هوية رسمية.

## التقنيات

- Python
- Django
- SQLite للتشغيل المحلي
- HTML Templates
- CSS
- JavaScript Canvas لتوليد بطاقة PNG
- WhiteNoise/Gunicorn لإعدادات النشر

## هيكل المشروع

| المسار | الوصف |
|---|---|
| `config/` | إعدادات Django والروابط الرئيسية |
| `journey/` | منطق الجواز، المحطات، النماذج، والاختبارات |
| `journey/data.py` | بيانات المحطات والأسئلة والإجابات والتلميحات |
| `templates/` | صفحات HTML |
| `static/css/style.css` | التصميم والخطوط والتجاوب |
| `static/js/app.js` | تحميل البطاقة والمشاركة وتأكيد الحذف |
| `static/images/` | صور المحطات والأيقونات |
| `static/fonts/` | ملفات خط ثمانية |
| `manage.py` | أداة إدارة Django |
| `requirements.txt` | متطلبات المشروع |

## التشغيل على Windows

1. ثبّت Python 3.10 أو أحدث.
2. افتح PowerShell داخل مجلد المشروع.
3. أنشئ البيئة الافتراضية وثبّت المتطلبات:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. جهّز قاعدة البيانات:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
```

5. شغّل السيرفر:

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

6. افتح المتصفح على:

```text
http://127.0.0.1:8000/
```

لإيقاف السيرفر استخدم `Ctrl+C`.

## تشغيل سريع على Windows

يمكن تشغيل الملف:

```text
start_windows.bat
```

يقوم بتجهيز البيئة، تثبيت المتطلبات، تشغيل الهجرات، ثم تشغيل السيرفر.

## التشغيل على macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
```

ثم افتح:

```text
http://127.0.0.1:8000/
```

## الاختبارات

```powershell
.\.venv\Scripts\python.exe manage.py test
```

أو إذا كنت تستخدم Python العام:

```powershell
python manage.py test
```

## لوحة الإدارة

لإنشاء مستخدم مدير:

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

ثم افتح:

```text
http://127.0.0.1:8000/admin/
```

تعرض لوحة الإدارة الجوازات والأختام. أما أسئلة المحطات ومحتواها فتُعدّل من `journey/data.py`.

## حفظ التقدم

يحفظ المشروع الجواز والأختام في قاعدة البيانات، ويربطها بجلسة المتصفح. إذا تم حذف ملفات الارتباط من المتصفح فقد لا يستطيع المستخدم الوصول للجواز نفسه من جديد، لكن السجل يبقى في قاعدة البيانات إلى أن يتم حذفه من داخل التطبيق أو لوحة الإدارة.

## ملفات لا تُرفع عادة إلى GitHub

هذه الملفات موجودة في `.gitignore` ولا يُفترض رفعها:

- `.venv/`
- `__pycache__/`
- `*.pyc`
- `db.sqlite3`
- `.local-secret`
- `staticfiles/`
- `.env`

## النشر

المشروع يحتوي على إعدادات جاهزة للنشر على Render. راجع ملف:

```text
RENDER_SETUP.md
```

يتضمن خطوات متغيرات البيئة، قاعدة البيانات، أوامر البناء، وأمر التشغيل.
